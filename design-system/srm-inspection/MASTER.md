# SRM 巡检中心界面设计规范

适用对象：PC 端中文企业巡检后台。面向运维、测试和系统管理员，帮助用户判断系统健康、识别异常、查证运行结果。本次兼容范围为桌面窗口，不包含手机端适配。

## 设计依据与边界

- 使用 `ui-ux-pro-max` 的本地设计系统、趋势图和键盘操作查询，选取适合企业后台的简洁网格、高对比、语义色和数据明细原则。
- 查询返回的营销落地页结构、外部字体、绿色主按钮和滚动入场动画不适用本项目，未采用。本文是结合现有产品审查后的规范，不是未经筛选的生成结果。
- 使用 `design-taste-frontend` 的改版审查、保留品牌、排版、间距、主题一致性和交付检查原则。该 skill 明确将密集后台排除在其核心适用范围之外；后台与图表决策以 `ui-ux-pro-max` 为主。
- 沿用原生 HTML / CSS / JavaScript。使用蓝色品牌与现有导航，保持页签、页面 ID、认证、巡检和报告接口。
- 不引入组件库、在线字体、图片或动效运行库。这是现有产品的原生样式演进，不宣称实现 Fluent 或 Carbon 官方设计系统。
- 设计参数：布局变化 3/10、动效 2/10、信息密度 7/10。可读性与异常识别优先。

## 信息层级

1. 页面标题、当前系统与环境、最新巡检时间、数据更新时间。
2. 需要关注的异常，按未恢复告警、最近失败、周期异常、待配置、首次运行排序。
3. 当前快照与周期指标，明确区分统计口径。
4. 趋势、结果构成、模块健康度、慢检查项。
5. 可展开的数据明细、最近运行摘要和工作流入口。

不得将“无记录”“加载失败”表达为“运行正常”。首次运行与失败状态必须提供下一步操作。

## 色彩与主题

全系统主色为 `#2563EB`，用于执行及登录按钮、选中导航、链接与通过率图表；浅色选中背景为 `#EFF6FF`。深色模式保留 `#2563EB` 实心按钮及白色文字，链接、焦点与图表使用同系亮蓝 `#60A5FA` 以保持对比度。成功、失败、待核实为语义色；耗时采用青色，避免与待核实混淆。所有状态同时使用文字或符号，不能只依赖颜色。

| `--foreground` | `#223047` | `#e7edf7` | 标题、关键数字 |
| `--muted` | `#536279` | `#aeb9cc` | 说明、正文、刻度 |
| `--subtle` | `#647187` | `#9ba8bd` | 次级说明 |

| `--accent` | `#2563EB` | `#60A5FA` | 链接、选中、焦点 |

## 中文排版与数字

- 本地系统字体：`-apple-system, BlinkMacSystemFont, PingFang SC, Microsoft YaHei, Segoe UI, sans-serif`。
- 桌面页标题 28px；区块标题 16px；数据标签 12–13px；关键数字 30px。
- 辅助文本和图表刻度原则上不低于 12px。指标内紧凑标签可用 11px，但不能承载唯一的状态说明。
- 正文行高 1.5–1.7。中文标题不使用负字距或全大写装饰标签。
- 使用 `font-variant-numeric: tabular-nums` 保持数字对齐；百分比保留一位小数，耗时附单位。
- 业务名称、异常说明和运行标识可换行。不要以省略号隐藏唯一的诊断信息。

## 空间与形状

- 以 4px 为间距单位：常用 8 / 12 / 16 / 20 / 24px。
- 数据面板圆角 12px，提示区 10px，按钮与异常项 8px，紧凑状态标签 5–6px。
- 面板用边框区分；只有浮层使用阴影。指标共享一个摘要面板，以细分隔线组织。
- 桌面窗口不超过 1280px 时，趋势图占整行，诊断区域两列；不超过 1050px 时，指标两列、筛选换行。更宽窗口采用趋势与结果构成主次分栏。
- 页面不横向溢出。运行明细表在独立容器内横向滚动，保留列含义。

## 图表规则

- 趋势采用原生 SVG。按容器实际 CSS 宽度设置 viewBox，刻度保持 12px；窄屏减少时间刻度，日期和时间分两行。
- 通过率固定 0–100% 左轴；耗时右轴附单位。实线表示通过率、虚线表示耗时、点线表示上一周期通过率。
- 上一周期按最近一轮向前对齐，明确日期不同；数据不足时不拉伸对比序列以制造完整覆盖。
- 每轮构成附检查项数量轴。高密度时减少柱顶标签，具体数量通过提示与明细表读取。
- 图表提供可见文本摘要和可展开的结构化数据表。参考 [W3C 复杂图像文本替代指引](https://www.w3.org/WAI/tutorials/images/complex/)。
- 图表一次进入一个键盘焦点：方向键切换、Home/End 到首尾、Enter/空格打开报告、Escape 关闭提示。重绘尽量保留焦点。
- 失败与跳过分开表达；存在跳过不能直接绘制为失败节点。

## 动效与可用性

- 只用约 160ms 的颜色、边框反馈，以及一次 500ms 的数据变更提示。
- 总览不添加循环脉冲、滚动动效、数字滚动或图表绘制入场。数据更新不以动画完成为条件。
- 健康卡片采用用户于 2026-10-14 选定的“右侧精密雷达”：健康状态绿色 8 秒慢扫，巡检中蓝色 2.5 秒快扫；异常停止扫描并突出红色信号点，待执行静止。雷达仅作状态氛围呈现，不表示检查项进度或数量；结果文字与完成时间仍以运行证据为准。页面不可见、切换到其他工作区或开启减少动效时暂停或关闭扫描。
- `prefers-reduced-motion: reduce` 时关闭总览动画和过渡。
- 保留可见键盘焦点，图表焦点另有描边，浮层不能超出视口。
- 时间筛选支持方向键和 Home/End；运行数据使用原生 `details` 和有表头的 `table`。
- 载入失败使用页面内提示和重试。若已有成功快照，明确提示正在保留旧数据。

## 验收

验证浅色与深色、正常与异常、首次运行、单条与多条记录、空范围、部分对比、接口失败与重试；覆盖 PC 窗口 1024 / 1280 / 1366 / 1440 / 1920px，并检查侧栏折叠、键盘操作、减少动效和控制台错误。
